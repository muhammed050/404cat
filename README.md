# 404 CAT

Official website for **404 CAT / $404**.

## Stack
- Next.js App Router
- React
- TypeScript
- Plain CSS
- Vercel-ready

## Local development
```bash
npm install
npm run dev
```

## Environment
Optional:
```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example
```

Until a custom domain is attached, the project defaults metadata links to `https://404cat.vercel.app`.

## Notes
The contract and Pump.fun link are intentionally not hard-coded before launch. Add verified links only after the token is created.
